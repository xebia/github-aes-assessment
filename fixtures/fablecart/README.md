# FableCart Retail fictional fixture

Every file in this directory, including issues, repository excerpts,
questionnaire answers and `agentrc-readiness.json`, is synthetic evidence for a
fictional organization and workflow. Nothing here describes a real client,
system, customer, repository assessment or production result.

`agentrc-readiness.json` is an unmodified AgentRC `CommandResult` captured
against the small fictional repository fixture. The manifest marks the imported
evidence as fictional; retaining the envelope unchanged makes its provenance and
parser behavior testable.
